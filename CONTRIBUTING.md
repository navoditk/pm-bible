# Contributing New Knowledge

Every new concept should ideally add or update four artifacts:

1. `reference/.../<concept>.md`
2. one learner notebook or exercise where appropriate
3. reusable implementation in `src/pm/` if computational
4. tests

## Reference-page standard

Use `templates/CONCEPT_TEMPLATE.md`.

## Notebook standard

Use `templates/NOTEBOOK_TEMPLATE.md`.

## Use-case standard

Use `templates/USE_CASE_TEMPLATE.md`.

## Evidence standard

Prefer:
1. official/primary sources,
2. major educational institutions,
3. established practitioner sources,
4. textbooks/papers.

Store links in `resources/` and link them from the concept page.
