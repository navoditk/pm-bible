# Equity — Free Resources

## CFA Institute
Equity valuation and portfolio-management frameworks — same source used
for `portfolio_foundations.md` and `active_management.md`.

Use for:
- DDM and relative valuation frameworks
- CAPM, beta, and required-return terminology
- style/factor investing vocabulary

## Aswath Damodaran (NYU Stern)
Valuation teaching materials and data:
https://pages.stern.nyu.edu/~adamodar/

Use for:
- DDM and relative valuation walkthroughs
- implied equity risk premium and industry beta datasets
- cost-of-equity estimation

## MIT OpenCourseWare
Finance Theory I (same course as `fixed_income.md`):
https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/

Use for:
- CAPM derivation and intuition
- equity risk premium foundations

## Public data
Kenneth R. French Data Library:
https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html

Use for real Fama-French value/size/momentum factor return series — the
right way to ground `style_tilt` / factor exposure exercises in actual
data rather than invented numbers.

## Official Python library docs
numpy (`beta`, factor exposure math) — same library docs used across the
