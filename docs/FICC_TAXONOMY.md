# FICC Taxonomy

## Rates
bonds, curves, forwards, futures, swaps, swap spreads, carry/roll, duration/DV01/KRD, hedging.

## Credit
spread measures, spread duration, OAS/Z-spread, credit curves, CDS, default/recovery, migration, IG/HY.

## Securitized
MBS, ABS, CMBS, prepayment, negative convexity, extension/contraction, OAS.

## FX
spot, forwards, carry, hedging, basis.

## Commodities
futures curves, contango/backwardation, roll yield.

Each major topic should eventually have:
reference page + notebook/lab + implementation where computational + use case.
