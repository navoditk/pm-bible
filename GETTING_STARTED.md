# Getting Started

## Recommended first session

Do only these steps:

1. Set up the remote GitHub repo and local clone using `SETUP.md`.
2. Run `pytest`.
3. Open `ROADMAP.md`.
4. Open `curriculum/bootcamp_01_foundations/README.md`.
5. Read Module 1 resources.
6. Open `notebooks/foundations/01_returns_and_compounding.ipynb`.
7. Complete the first `MANUAL FIRST` exercise without an agent.
8. Only then start Codex using the prompt in `agents/CODEX_WORKFLOW.md`.

## The intended experience

A topic such as covariance should be encountered in this order:

1. 15–40 minutes of curated free reading/video.
2. A prediction question.
3. A small hand calculation.
4. A learner notebook with an empty implementation cell.
5. A code recipe you manually type.
6. Experiments that change assumptions.
7. Extraction into `src/pm/`.
8. Unit tests.
9. A five-sentence PM explanation.
10. Optional tutor-agent deep dive.

## Do not start by asking an agent to build the repo

The repo already contains the structure. Coding agents are most valuable after you have attempted the financial logic yourself.

## Version-control workflow

Read `SDLC.md` and `docs/GIT_WORKFLOW.md` before starting the first notebook. Work on a short-lived branch and push at the documented checkpoints.
