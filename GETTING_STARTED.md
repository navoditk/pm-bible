# Getting Started

This file is maintained as a compatibility entry point. The canonical docs live in [docs/getting-started.md](docs/getting-started.md).

## Recommended first session

1. Read [docs/getting-started.md](docs/getting-started.md)
2. Set up GitHub workflow using [SETUP.md](SETUP.md)
3. Run the test suite
4. Start with the foundations bootcamp
5. Complete the first manual exercise before asking an agent for help

## First milestone

The recommended starting point is:

- `curriculum/bootcamp_01_foundations/README.md`
- `notebooks/foundations/01_returns_and_compounding.ipynb`

## The intended experience

A concept such as covariance should be encountered in this order:

1. Curated reading and concept review
2. A prediction question
3. A small hand calculation
4. A learner notebook with an empty implementation cell
5. A code recipe you manually type
6. Experiments that change assumptions
7. Extraction into `src/pm/`
8. Unit tests
9. A concise PM explanation
10. Optional tutor-agent deep dive
