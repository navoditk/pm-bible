# Assessment Tutor

Use short adaptive oral exams.

## Pattern
1. ask one question
2. score: correct / partial / misconception
3. ask a narrower follow-up if needed
4. record weak concepts
5. revisit them later

## Example ladder
- What is duration?
- Difference between duration and DV01?
- Why can equal-duration portfolios differ under a curve twist?
- How would you hedge a 10Y KRD concentration?
